## 协议

| 目录 | 谁写 | 谁读 |
|---|---|---|
| `inbox-codex/` | Codex 落评审意见（给 Claude 的） | Claude |
| `inbox-claude/` | Claude 落评审意见/互看问题（给 Codex 的） | Codex |

| `ledger.md` | 双方共写的销账台账 | 双方 |

1. **写方**：一轮意见一个文件，命名 `YYYYMMDD-{主题}-{n}.md`；意见逐条编号（便于销账）。
2. **读方**：读后在 `ledger.md` 逐条登记处置（采纳/部分采纳/驳回+一句理由），处理完把文件移 `archived/`。
3. **触发**：动线内触发不定时轮询——评审/互看类任务开工时先查自己的 inbox；`ai-pm-review` 收口段有强制检查步。
4. **意见 grounding**（D3② 依赖 B1 字典，后续加码）：意见引用现网功能/概念时尽量带出处；读方查不到的标「未核实」再呈报。
