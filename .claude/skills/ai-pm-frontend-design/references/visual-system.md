# Visual System

本文件用于把情境化设计落成稳定的布局、间距、字体、色彩和动效系统。目标是业务可信，不是炫技。

## 1. Anti AI Slop

出现以下迹象时必须重做视觉方向：

- 紫蓝渐变、暗色发光、玻璃拟态、霓虹边框被当作默认高级感。
- 渐变大字、hero metric、大数字装饰化但没有业务含义。
- 卡片网格机械重复：图标 + 标题 + 描述，整页同构。
- 灰白卡片 + 蓝按钮 + 空泛图标，像通用 SaaS 模板。
- 全部居中、全部同间距、所有元素视觉重量相同。
- 大量装饰图形、噪声、光斑、炫酷动效不能解释业务含义。

## 2. Spacing And Layout

- 使用 4pt 间距体系：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96。
- 用语义 token，如 `--space-sm`、`--space-md`，不要散落随机数值。
- 相关元素距离紧，不同分组距离松；不要所有 gap 一样。
- 用 `gap` 管 sibling 间距，减少 margin 互相抵消。
- 卡片只用于可比较、可操作或需要明确边界的内容；不要卡片套卡片。
- B 端和数据界面允许高密度，但必须有清楚分组、表头、筛选和状态。
- 移动端用单列和渐进展示，桌面端用侧栏、分栏、主次面板释放空间。

## 3. Typography

- App/原型 UI 使用固定 `rem` 字阶，不按 viewport 线性缩放字号。
- 常用字阶：caption、secondary、body、subheading、heading、display；容器越小标题越克制。
- 正文不低于 14px；移动端正文优先 16px。
- 标题层级不要只靠字号，结合字重、颜色和上下间距。
- 数据表、金额、百分比、序号使用 `font-variant-numeric: tabular-nums`。
- 字体最多 2 个家族；业务原型优先可靠系统字体，除非用户明确需要品牌字体。
- 不使用负 letter-spacing；中文界面默认 letter-spacing 为 0。

## 4. Color

- 色彩先服务语义：主操作、成功、警告、错误、信息、禁用、待处理。
- 选择 1 个主色、1 个辅助色、1 个强调色即可；不要彩虹化。
- 中性色可带轻微冷暖倾向，避免大面积纯黑纯白。
- 有色背景上不要用普通灰字；使用同色系深浅或透明白/黑保证对比。
- 图表颜色必须解释分类或状态，不做装饰性配色。
- 不只靠颜色表达含义，状态还要配合图标、标签或文案。

## 5. Motion

- 动效只服务状态变化、层级关系、反馈和引导。
- 常用时长：即时反馈 100-150ms；状态切换 200-300ms；复杂展开 300-500ms。
- 只动画 `transform` 和 `opacity`；不要动画 width、height、top、left、margin、padding。
- 使用自然减速曲线，不使用 bounce / elastic。
- 支持 `prefers-reduced-motion`，降低或关闭非必要动效。

## 6. Product Fit

- B 端：克制、扫描效率、稳定导航、清楚筛选和批量操作。
- 教育：角色分明，教师侧重管理效率，学生侧重路径和反馈。
- Agent：输入、思考、执行、失败、确认、人工修改入口必须可见。
- 数据：优先解释趋势和异常，再展示明细。
- 移动端：路径、反馈、触控和单手可达优先于信息密度。
