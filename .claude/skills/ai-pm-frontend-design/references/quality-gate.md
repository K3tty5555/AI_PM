# Quality Gate

落盘或交付前按 12 分制自检；任一维度低于 3 分或总分低于 9 分，先修复再交付。

## 1. PRD Coverage (0-4)

- 4：页面、主流程、核心规则、关键状态、角色差异均覆盖。
- 3：主流程完整，少量次要状态可接受。
- 2：页面存在但流程断裂或状态明显缺失。
- 1：只做了静态结构，无法支撑评审。
- 0：与 PRD 目标不符。

## 2. Interaction Experience (0-4)

- 4：核心任务可走通，点击/输入/筛选/切换都有真实状态变化。
- 3：主操作可用，个别次级操作简化但不误导。
- 2：有按钮但大量无反馈或假交互。
- 1：基本是静态页面。
- 0：用户无法理解如何操作。

## 3. Visual Design (0-4)

- 4：视觉方向清楚，信息密度、组件、层级、业务假数据可信。
- 3：整体可信，少量细节可继续打磨。
- 2：通用模板感明显，信息层级或密度不适配场景。
- 1：灰白卡片堆叠、样式松散、内容占位严重。
- 0：视觉混乱或影响阅读。

## Required Fixes Before Delivery

- 文本重叠、竖排、按钮溢出、图表挤压、移动端横向爆屏。
- 只有默认态，没有空/加载/错误/成功。
- 主导航使用 `window.open` 代替产品内切换。
- 业务数据使用“测试数据 / 示例内容 / 张三 / Lorem ipsum”。
- B 端做成营销页，C 端做成后台表格脸。
- Agent 产品缺少 AI 状态、结果确认、用户修改或失败兜底。

## Delivery Note

如果因为当前环境不能截图或运行浏览器，只能说明“未做视觉截图核对”。不要声称已完成视觉验证。
