# 模式 B：登录态一手实探手册

> SKILL.md 步骤3「模式 B」的完整操作细则。走登录态实探前**必读**。
> 这是实探纪律的**单一事实源**——SKILL.md 只放触发判断+指针，不重复这里的条文。
> 为什么有这套：公开页只有宣传话术，竞品真实功能颗粒度、真实数据规模、真实使用情况，只有登进生产系统才看得到（实战：一个竞品账号即坐实"对方已拿下某标杆校+渗透某联考圈"，这是公开页永远拿不到的）。

## 1. 触发条件

满足任一即可走模式 B；都不满足 → 只走模式 A（公开页）：
- 用户明确提供可登录的竞品账号；
- 现场调研/客户陪访能登；
- 试点校授权登录。

## 3. 只读安全纪律（铁律，逐条守）

真实账号是别人的生产数据，任何写操作都可能造成真实影响。所以：

1. **开浏览器前先获用户当次授权**——复用项目"Playwright 未经允许禁止跑"纪律；开浏览器这个动作本身就要先问，不是只在保存前才问。
2. **全程只读**：不点 保存 / 提交 / 发布 / 开始批改 / 删除 / 改设置；每个敏感动作前自检"这会不会落数据"。
3. **必须打开编辑器看面板时**：看完用系统自带的"未保存将丢失"确认框**丢弃退出**，绝不点保存。
4. **别切用户正在登录/查看的页**：用户手动登录时，AI 先停所有 navigate，等用户说"好了"再动（踩过坑：把人登录页切走，得重登）。
5. **SSO 子系统可能要单独登录 / 需增购**：拿不到就公开信息兜底——**子系统独立性本身也是情报**（说明竞品是多系统拼装、SSO 不互通）。
6. **真实账号 = 敏感操作**：按"对外/不可逆动作先确认"对待，拿不准就停下问用户。

## 4. 降级决策表

实探不是非全有即全无，按能拿到的层级逐级降级，每级把能力损失明示用户：

| 层级 | 能拿到 | 失败触发 → 降到 |
|------|--------|-----------------|

| 公开页实探（模式A·Playwright） | 官网 SPA 渲染后内容 | Playwright 不可用 → WebFetch |
| WebFetch 纯文本 | 静态 HTML | —（明示：拿不到登录态与 JS 渲染内容，结论可能不完整）|

## 5. 元情报意识

页面内容之外，**账号本身就是情报**：挂了哪些组织、能进哪些模块、哪些子系统进不去（独立登录/无权限/需增购）——这些往往比页面数据更说明竞品的市场布局与产品架构。随手记下来。

## 7. MCP 操作避坑（实战血泪）

- **`browser_evaluate` 脚本不用正则、不用嵌套引号**——工具调用是 JSON 编码，正则字面量 `/.../ ` 和多层引号会触发 "malformed tool call"。改用 `String.includes()` / `===` + 单层引号，复杂筛选拆成多次简单调用。
- **对 Vue/SPA 元素，`el.click()` 或合成 MouseEvent 不触发 `@click`**（点了没反应）。正解：evaluate 里给目标元素 `setAttribute('data-go','x')` 打标记，再用 `browser_click` 带 selector `[data-go="x"]` 真实点击。
- SPA 卡片常把 `@click` 绑在外层 button/a，标记叶子 span 会点空——标记可点祖先（`closest('button,a')`）。
