# 竞品对标卡（battlecard 本地化）

> 已过 `localization-card.md` 三步过滤。这是 ai-pm-research 的一个加层，不是新命令。
> 补的是 ai-pm-research 唯独缺的那块：现在能产"格局 / 对比 / 差异化机会"的**战略报告**（偏一次性），**就差"对单个对手、可随身带、对销售可用"的实战卡**（偏战术、反复用）。

## 换场景（美式→大陆）

美式 battlecard 多是 SaaS 销售对单个 SaaS 竞品的话术卡。大陆换土壤到 **B 端 / G 端**：招投标、客户决策会、一线销售被客户拿友商压价/比较的场景。

## 硬触发（防沉睡）

只在以下场景 pull——普通竞品研究报告走 ai-pm-research 主流程，**不触发**：
- 用户要"给销售用的对标卡"/"客户拿竞品压价怎么答"
- 某个竞品变成**高频**压力（销售反复被同一个对手问倒）

## 对标卡结构（单竞品一张，求精不求全）

| 栏 | 写什么 |
|---|---|
| 这是谁 | 一句话定位 + 它的目标客户 |
| 它强在哪 | **1-2 个最关键**的真实强项（不堆全，**每条标来源**） |
| 它弱在哪 | **1-2 个**我们能打的真实软肋（**每条标来源**） |
| 客户为什么拿它比 | 它的钩子（客户嘴里常说的那句"人家 X 有……"） |
| 我们的差异化话术 | **一句话、销售能直接说出口**，不堆参数 |
| 常见质疑 → 怎么接 | 2-3 条客户会问的，配得体的回应 |
| 它最近动作 → 我们姿态 | 它出了新功能时，跟 / 不跟 / 怎么接 |

## 对销售的铁律

- 话术**一句话能说出口**，不是一段参数。一线背不下来的卡 = 没用的卡。
- **诚实**：不黑竞品、不吹自己，只讲**真实差异和适用边界**——否则一线照卡说、客户一戳就穿，比没卡更糟。

## PM altitude（守住）

不写竞品的技术实现细节，不编造竞品数据；每条强弱项标来源（官网 / 应用商店评论 / 客户反馈 / 招投标信息）。

## 输出

可单独成卡 `03-competitor-report/battlecard-{竞品}.md`，或并入竞品报告附录。一竞品一卡，别揉成大表。

## 大陆反例（内嵌，2 组）

**反例 1 · 把战略报告甩给销售**
- ❌：客户拿友商压价，PM 把整份 7 章竞品研究报告丢给销售"自己看"。
- ✅：一张卡——它强在题库覆盖、弱在批改准确率和学情闭环；差异化话术"题库够用，且我们批完直接出学情报告"；配 3 条质疑应对。销售能背、能当场说。

**反例 2 · 黑竞品 / 吹自己**
- ❌：「友商垃圾，我们全面领先。」
- ✅：「友商题库更大是真的；我们的差异在批完直接出学情报告，适合要数据闭环的客户。」——讲真实适用边界，一线说出来才不被客户一戳就穿。
