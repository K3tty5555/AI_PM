# 智囊团质询卡（对成稿决策评审的对抗式审视协议）

> 定位：战略沙盘的姊妹模式——沙盘管"迷茫时发散建方向"，质询管"成稿后上会前攻框架"。
> 本卡是质询模式**五纪律与时点窗口的单一事实源**，别处只留指针。

## 一、定位与触发时机

- **对象**：成稿的决策评审型 PRD（决策评审 doctype 专用；普通功能 PRD 不适用——它的失败模式在执行面，六角色评审已覆盖）。
- **时点窗口**：成稿自检通过后、**首次正式发出/推云前**（时点窗口只在本节定义，别处引用此节）。此窗口属首评周期，修订日志后果按判断卡 §八 口径熔进 V1.0，此处不复述。
- **分工**：质询只打"框架/路线/推荐本身站不站得住"这一层。与既有关卡**有交叉但不重复**：六角色评审与上线前风险预演会触及用户价值、战略风险和执行可行性，driver 管 PM 风格 lint、八条必答管结构完整——但没有任何一环强制按"多视角攻击具体决策点 + 主持人逐条核原文"的协议做对抗收敛，质询补的是这层专门深度。
- **怎么进入**：用户明确要求"对这份稿跑质询/对抗审视"时进入本协议（入口见 SKILL.md 快速边界的质询例外）。**不自动执行**——决策评审模板会在正式发出前主动提议一次，用户确认才跑、可跳过。

## 二、席位结构与议题选人

- **结构**：反方董事 1 席常驻（专职攻推荐结论）+ 4 席顾问按稿子的核心张力点换人。
- **选人方法**（沉淀的是判断，不是死名单）：先读稿，找出这份稿真正的张力在哪，再按张力配顾问类型——
  - 张力是"会不会被更简单的东西颠覆" → 请颠覆式创新视角；
  - 张力是"增长/成本账算不算得过来" → 请极致效率视角；
  - 张力是"用户心智/产品直觉" → 请产品哲学视角；
  - 张力是"飞轮/长期结构" → 请长期主义视角；
  - 定价稿、组织稿、合规稿……换对应的另外四类。
- 每席带独立分析框架发言，禁止五席说同一种话；全是名人金句、不落到这份稿=失败输出（与沙盘同标准）。

## 三、收敛协议五纪律（质询的内核——谁都能生成五个名人 persona 说金句，值钱的是这套收敛）

1. **质询非推演**：每席只准找"能改变决策"的攻击，不做泛泛发散；上限 1-2 条、不设下限，**允许交白卷**——找不到就明说"无"，硬凑配额的攻击比没有更糟，阴性结果如实收进清单。
2. **钉决策点**：每条攻击必须落到稿内具体决策点（决策点编号 / 某个框架 / 某个量化口径），空泛大词不算数。
3. **标"稿内接不接得住"**：每条标注"接得住 / 部分接得住 / 接不住"，并引原文位置——这一步把噪音和真问题分开。
4. **配待验证动作**：每条给一个上会前可做的 `[待验证]`，把批评变成活。
5. **主持人核原文**：收敛时逐条**核对**稿子原文再下判——这是抓稿内真矛盾的手段，也是防顾问编造稿外事实的唯一闸门，**绝不能省**。

## 四、事实边界纪律

- 完整协议见 `references/fact-boundary.md`（指针复用，不复制正文）。
- 质询专用加严：顾问只准攻**稿内逻辑**与**公开常识**；任何稿外"事实"（市场数据、竞品动向、用户偏好）一律降级进 `[待验证]`，不得当论据使用。

## 五、能力边界（老实话）

- 质询打的是**框架和论证**，不是事实。凡涉及私有数据（用户到底想不想要、竞品内部实情），顾问都够不着——这类交战略求证侦察兵去挖。
- 顾问会一本正经编造稿外事实。主持人核原文那道闸省掉的话，质询就从帮手变成噪音源，对决策稿比没有还糟。

## 六、产出与落点（先会话收敛、后择优落稿）

- **产出**：攻击清单（每条：哪席提的 / 钉哪个决策点 / 接得住标注+原文位置 / 配套 `[待验证]`）。
- **候选先在会话内收敛**：主持人逐条核原文、筛掉噪音——未被接受的候选死在会话里，不进稿、不落独立清单文件、不建第二本台账。
- **PM 接受的才写回 PRD**：改正文，或以 `[待验证]` 标记进风险/待拍段。**结论的最终落点=PRD 内容修改本身，不另建稿外档案。**

## 七、与战略求证的接力

- 会话内核完原文的 `[待验证]` 项可**直接交 `ai-pm-strategy-verify`**（不必等落稿）；只传清单、不传稿件全文，与沙盘"后半场接力"同口径。
- 求证结论回来后，由 PM 判断写回稿内；求证侧若需落盘，按它自己的 storage 规则走。
- 质询与求证独立可用、不强制成对：质询找软肋，求证坐实或推翻。

## 八、样本台账

> 条目格式写死（防膨胀、防隐私滑坡）：`日期 + 阳性/阴性一句话（N 处真矛盾 / 交白卷；不落稿名/产品名/数据） + 过程见本机 docs/（仅本机）`。
> 只收**实际执行过质询**的轮次：用户跳过提议=不算样本、不记账；执行后全交白卷=阴性样本、照记；路由冒烟测试不算样本。
