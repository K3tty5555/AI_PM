# 输出模板

正式沉淀固定生成核心产出。文件内容是思考材料，不是最终战略规划。

## 项目级产出

```text
00-session.md
01-strategy-memo.md
02-assumptions.md
03-briefing-qa.md
```

## 产品级产出

```text
00-session.md
01-strategy-memo.md
02-project-portfolio-map.md
03-assumptions.md
04-briefing-qa.md
```

## 01-strategy-memo.md 战略思考备忘录

```markdown
# {议题} · 战略思考备忘录

## 这次真正讨论的问题

{重新定义后的问题}

## 当前更清晰的判断

- [用户判断] ...
- [智囊团推演] ...

## 可选方向

| 方向 | 成立条件 | 主要风险 | 当前证据状态 |
|---|---|---|---|
| A | ... | ... | [待验证] ... |
| B | ... | ... | [资料事实] ... |

## 当前不能下结论的原因

- [待验证] ...
- [高不确定假设] ...

## 组织协同风险

- [高不确定假设] ...

## 可带去讨论的表达口径

{用于和老板/同事/团队继续讨论的表达，不写成最终决策}
```

禁止在本文件写：

- 最终战略规划
- 已拍板 Roadmap
- 具体功能排期
